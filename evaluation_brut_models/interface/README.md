# Interface de comparaison

Page HTML/CSS statique des résultats d'évaluation Text-to-SQL. Tous les scores
sont figés directement dans `index.html` : il n'y a ni import de JSON, ni script
JavaScript, ni dépendance réseau.

Les colonnes sont volontairement rangées par modèle, puis par configuration :
zero-shot, few-shot à 2 exemples et few-shot à 4 exemples.
