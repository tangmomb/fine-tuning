# Interface de comparaison

Base front-end statique, sans backend. La première version contient les deux
runs présents dans `runs_scaleway` au 22 septembre 2026. Les valeurs initiales
sont définies dans `runs-data.js`.

L'interface peut déjà importer manuellement le dossier d'un run, ou les deux
fichiers `generation_manifest.json` et `sql_execution/metrics.json`. Aucune
donnée n'est envoyée sur le réseau.
